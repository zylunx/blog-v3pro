## 前言

为了体检时测视力，我临时起意去楼下眼镜店配了一副。店员说 150 元就能配，半小时取镜，我当时还觉得挺便宜。

结果体检完戴着走了没多久就发现不对劲：视野严重畸变，四周的东西像被向内吸进去一样，看什么都扭曲，眼睛和脑袋很快就累。上网一查才知道，这是典型的球面镜片问题——便宜是真便宜，但根本没法长时间戴。

## 问题显现：四周向内收缩

具体症状很集中：

- 看任何东西都有畸变，周边视野尤其明显
- 四周景物明显向内收缩，类似枕形畸变（pincushion distortion）
- 戴久了眼睛酸胀、脑袋发晕
- 走路时甚至有轻微的不适感

回家后我立刻查资料，才确认这是**球面镜片（Spherical Lens）**的典型缺点：曲率恒定，从中心到边缘像差迅速增大。150 元这个价位基本就是球面镜片加普通材质，边缘厚重、光学畸变明显。

## 球面镜片与非球面镜片

这是我这次最大的教训，两者的差别远不止价格：

| 项目 | 球面镜片（Spherical） | 非球面镜片（Aspherical） |
| :--- | :--- | :--- |
| 价格 | 便宜，100-200 元常见 | 较贵，通常 300 元以上 |
| 厚度 | 边缘较厚，度数越高越明显 | 更薄更轻，同度数可薄 20-40% |
| 畸变 | 明显，周边视野扭曲、向内收缩 | 极小，视野更自然清晰 |
| 佩戴舒适度 | 长时间戴容易累、头晕 | 舒适，可长时间佩戴 |
| 适用人群 | 仅建议轻度、临时应急使用 | 推荐大多数人，尤其是经常用眼者 |
| 体检临时用 | 能凑合，但不推荐 | 更好的选择 |

原理可以一句话概括：球面镜片曲率恒定，边缘像差大；非球面镜片曲率从中心到边缘逐渐变化，能显著减少球差、弯曲畸变和周边模糊。想深入了解可以看 [球面镜片和非球面镜片的区别](https://www.superclearoptical.com/pages/球面鏡片和非球面鏡片的分別)。

::alert{type="warning" title="下单前一定要问的一句"}
直接问店员“这是球面还是非球面”，并要求写在配镜单上。只报度数和价格、对镜片类型含糊其辞的，通常就是球面片。
::

## 我总结的几条教训

1. 别贪便宜。150 元的眼镜大概率是球面镜片加低折射率材质，短期能用，长期遭罪。
2. 提前做功课。至少要知道球面与非球面的区别，并在下单前问清楚用的是哪一种。
3. 明确告知用途。长期佩戴或经常用眼的话，直接指定非球面镜片，折射率优先选 1.60 或 1.67。
4. 接受稍贵的价格。多花 100-200 元换非球面，舒适度完全不是一个级别。
5. 线上与线下各有优劣。线下能试戴但容易被推销，线上参数透明，首次验光还是建议线下做。
6. 体检专用的可以走便宜方案，但别指望它顺便成为日常眼镜。

::alert{type="tip" title="如果只是体检当天戴一次"}
也可以找朋友借一副度数接近的旧眼镜，或者问问店家有没有临时租借。为了半天时间花几百块配一副日常根本戴不了的眼镜，性价比很低。
::

## 最后

这次经历让我重新理解了那句“没有调查就没有发言权”——在和眼睛健康直接相关的事情上，图一时便宜的代价，往往要加倍偿还。

我已经打算去重新配一副非球面镜片了。多花的钱换来的是不累、不晕、不畸变，这笔账其实很好算。
