如果你能看到这一段，说明解锁成功了。这篇演示文章在构建期就把正文加密，浏览器本地用密码派生密钥解密后再渲染——下面的元素都来自构建期生成好的渲染结果，用来确认排版、高亮和组件在解密后都能正常还原。

```ts [greet.ts]
function greet(name: string): string {
  // 解密后这行高亮应当和正常文章一致
  return `Hello, ${name}!`
}

console.log(greet('Ember'))
```

## 二级标题：MDC 组件

告警组件正常显示：

:::alert{type="tip" title="关于密码保护"}
正文以解析后的 minimark 树形式加密，因此 MDC 组件、代码高亮、KaTeX 都在构建期生成、随密文一起带走，解密后无需重新渲染。
:::

折叠块也能展开：

:::folding{title="展开：构建期做了什么"}
1. 读取 frontmatter 的 `password`；
2. 把正文 minimark 树用 PBKDF2-SHA256（210k 迭代）派生的密钥做 AES-256-GCM 加密；
3. 密文写到 `_locked/{hash}.json`，正文在内容库里换成占位段落，`password` 当场丢弃；
4. 搜索索引、atom.xml、sitemap、llms.txt 不再收录这篇。
:::
